## 项目介绍

Screenity 是一款免费、开源（GPL-3.0 协议）的 Chrome 浏览器屏幕录制扩展，目前 GitHub 已超过 18000 Star。它的核心理念是：**录屏工具不应该收集你的数据，也不应该给功能设限。**

项目地址：[https://github.com/alyssaxuu/screenity](https://github.com/alyssaxuu/screenity)

市面上很多录屏工具要么有水印、要么限时长、要么需要注册账号还偷偷上传你的录制内容。Screenity 反其道而行：无需注册、无录制时长限制、无水印、不收集任何用户数据，核心功能全部可以在离线环境下使用。它由开发者 Alyssa X 创建并开源维护，适合需要快速录制屏幕、制作教程、录制产品演示或反馈 Bug 的场景。

## 核心功能

### 1. 多模式录制

- **标签页录制**：录制单个浏览器标签页的内容
- **桌面录制**：录制整个屏幕或特定窗口
- **摄像头录制**：单独录制摄像头画面，或与屏幕画面画中画叠加

所有模式均无录制时长限制，录制过程中可以随时切换。

### 2. 实时标注工具

录制过程中可以在屏幕上直接绘制：画笔、箭头、文字、高亮、图形等，方便在讲解时突出重点，无需后期再加工。

### 3. AI 摄像头背景

摄像头画面支持 AI 背景虚化和替换，不需要绿幕。适合远程演示时保护隐私或保持画面整洁。

### 4. 缩放与点击高亮

- **缩放**：录制时可以对画面局部放大，引导观众注意力
- **点击高亮**：鼠标点击位置自动显示高亮光圈，让观众清楚知道你在操作哪里

### 5. 敏感信息模糊

录制前或录制中可以对页面上的敏感区域（密码、个人信息、内部数据等）添加模糊遮罩，避免隐私泄露。这对于录制涉及真实系统操作的教程特别实用。

### 6. 内置剪辑编辑器

录制完成后不需要跳转到第三方工具，内置编辑器支持：
- 裁剪头尾多余片段
- 删除中间不需要的段落
- 调整播放速度

### 7. 多格式导出与分享

- **导出格式**：MP4、GIF、WebM
- **Google Drive 上传**：一键上传到 Google Drive 生成分享链接
- **本地保存**：直接下载到本地

### 8. 隐私与离线

- 不需要注册账号，安装即用
- 不收集、不上传任何用户数据
- 核心录制功能可完全离线使用（Google Drive 上传等在线功能除外）

## 使用方法

### 方式一：Chrome 应用商店安装（推荐）

直接在 Chrome Web Store 搜索 "Screenity"，或访问项目 README 中的商店链接，点击"添加到 Chrome"即可。安装后浏览器右上角会出现 Screenity 图标，点击即可开始录制。

### 方式二：自托管 / 开发版本

如果你不想从应用商店安装，或想使用最新开发版本：

1. 前往 [Releases 页面](https://github.com/alyssaxuu/screenity/releases) 下载最新 `Build.zip`
2. 解压到本地文件夹
3. 打开 Chrome，地址栏输入 `chrome://extensions`
4. 开启右上角"开发者模式"
5. 点击"加载已解压的扩展程序"，选择解压后的文件夹

### 从源码构建

需要 Node.js 14+：

```bash
git clone https://github.com/alyssaxuu/screenity.git
cd screenity
npm install
npm start
```

构建产物在 `build` 文件夹中，用上述"加载已解压的扩展程序"的方式加载即可。

### 录制流程

1. 点击工具栏 Screenity 图标
2. 选择录制模式：标签页 / 桌面 / 摄像头
3. 按需开启摄像头叠加、麦克风、标注工具
4. 点击"开始录制"
5. 录制中可随时使用标注工具在画面上标注
6. 点击"停止录制"，进入预览编辑器
7. 剪辑后导出 MP4/GIF/WebM，或上传 Google Drive

## 适用场景

- **产品演示与教程**：录制功能操作流程，配标注和语音讲解
- **Bug 反馈**：录制复现过程，比截图和文字描述高效得多
- **团队协作**：录制异步沟通视频，替代冗长会议
- **内容创作**：录制屏幕素材用于后期剪辑

## 小结

Screenity 的定位很清晰：一个够用、免费、不碰你数据的录屏工具。实时标注、AI 背景模糊、敏感信息遮罩、内置剪辑这些功能放在同类付费产品里也是中上配置，而它全部免费开源。对于经常需要录屏但又不想被各种限制和隐私条款绑住的人，这是 Chrome 浏览器上最值得安装的录屏扩展之一。
